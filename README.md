# الحدي — نظام إدارة مستخدمي الشبكة

نظام ويب لِإدارة مستخدمي الشبكة: إضافة مستخدمين، تجديد الاشتراكات، حساب المبالغ المستحقة، وتقارير مالية.

مبني بـ **React + Vite** وقاعدة بيانات **Supabase**.

## المزايا

- تسجيل دخول لفريق الإدارة (مشرف فقط)
- لوحة تحكم بإحصائيات حية (نشط، منتهي، المبلغ المستحق، إيرادات)
- إدارة المستخدمين: إضافة / تعديل / حذف / بحث / تصفية
- تجديد الاشتراكات مع تسجيل مبلغ وطريقة الدفع
- إدارة الباقات وأسعارها ومددها
- سجل كامل للاشتراكات والتجديدات
- تقارير: إيرادات شهرية، توزيع طرق الدفع، قائمة المستحقين (مع طباعة)
- **استيراد CSV** لتفريغ جرد الشهر مباشرة إلى النظام

## التشغيل محلياً

```bash
npm install
npm run dev
```

## الإعداد (Supabase)

1. أنشئ مشروعاً في [supabase.com](https://supabase.com)
2. افتح **SQL Editor** ونفّذ محتوى `supabase/schema.sql`
3. من **Authentication → Providers** فعّل Email (عطّل "Confirm email" لدخول فوري)
4. من **Settings → API** انسخ `Project URL` و `anon public key`
5. أنشئ ملف `.env` من المثال:

```env
VITE_SUPABASE_URL=https://YOUR-PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR-ANON-KEY
```

6. أعد تشغيل `npm run dev` — عند أول استخدام سترى خيار «إنشاء حساب أول»

## استيراد جرد الشهر

- من القائمة الجانبية اختر **استيراد CSV**
- ارفع ملف الجرد بصيغة CSV (الأعمدة: الاسم | العنوان | اسم المستخدم | الباقة | السعر | المدفوع | غير المدفوع | تاريخ الانتهاء)
- تُكتشف الباقات تلقائياً وتُستورد المستخدمون

## بنية قاعدة البيانات

| الجدول | الوصف |
|--------|-------|
| `packages` | الباقات (الاسم، السعر، مدة الأيام) |
| `users` | المستخدمون واشتراكهم الحالي |
| `subscriptions` | سجل الاشتراكات والتجديدات والمدفوعات |
| `profiles` | ملفات المديرين المرتبطة بحسابات المصادقة |

الباقات المعتمدة في الجرد: SPEED_1M (6) — SPEED_2M (8) — SPEED_3M (12) — SPEED_4M (16) — SPEED_5M (18) — SPEED_10M (35)، ومدتها 30 يوماً.
